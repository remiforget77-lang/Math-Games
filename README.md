# math-games

Game to learn multiplication by using visuals and fun

Jeux de maths pour enfants. Chaque jeu est un seul fichier HTML : double-cliquez dessus pour jouer.

- **pumpkin-pop.html**
- **WhiskerBalance.html** : additions, soustractions, multiplications et plus, avec des images (dizaines et unités, cadres de dix) et des chatons pour fêter les bonnes réponses. Marche sans Internet.
- **PythagoreTrainer.html** : la table de multiplication (table de Pythagore), avec de l'aide sur demande (rangées de points, stratégies) et la réponse cachée jusqu'à ce que l'enfant essaie. Marche sans Internet.

Whisker Balance et Table de Pythagore : français et anglais, avec lecture à voix haute.
